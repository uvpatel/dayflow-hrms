## 2. Community Channels

### GitHub Discussions
Join our [GitHub Discussions](https://github.com/uvpatel/dayflow-hrms/discussions) forum for:
- **Q&A**: Ask technical questions about architecture, features, or deployment.
- **Show & Tell**: Share how your organization uses or customizes Dayflow.
- **Ideas & RFCs**: Propose new feature concepts and discuss architectural directions.

### Discord Community
Connect in real-time with maintainers and fellow developers on our Discord server:
- **`#general`**: General chat and announcements.
- **`#help-desk`**: Setup and installation troubleshooting.
- **`#development`**: Technical contributions, PR reviews, and feature discussions.

---

## 3. Reporting Issues & Bugs

If you have identified a bug or unexpected behavior:

1. Search existing [GitHub Issues](https://github.com/uvpatel/dayflow-hrms/issues) to verify if the issue has already been reported.
2. If not reported, create a new issue using our **Bug Report Template**.
3. Include:
   - Reproduction steps
   - Expected vs actual behavior
   - Environment details (Node/Bun version, PostgreSQL provider, OS)
   - Relevant server console logs or browser console errors

> [!IMPORTANT]
> **Security Issues**: If you suspect a security vulnerability, do **not** open a public issue. Follow our [Security Policy](./SECURITY.md) and report directly to `security@dayflow.dev`.
